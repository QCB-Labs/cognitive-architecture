# mind

Two build specs, written alongside the research spec in `research/`.

- `INDEX-SPEC.md`: Stage 0. The agent's memory files are cut into small
  labelled cards; a wake reads one bounded wake card and recalls the rest.
  The code lives in the agent's harness, not here. Its read half is built
  and in use; the write half is being built in three briefs (§8).
- `BUILD-SPEC.md`: Stage 0 in outline, then the mind server. The server is
  not built yet and is reviewed before any code.
